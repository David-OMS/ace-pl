# Architecture Decision Records

One short file per significant technical decision, numbered in order: `0001-short-title.md`.
Write one when adding or replacing a library, changing the architecture, or departing from the standards.

## Template

```markdown
# 0000. Title

- Status: proposed | accepted | superseded by 0000
- Date: YYYY-MM-DD

## Context

What problem are we solving and what constraints apply?

## Decision

What we chose.

## Consequences

What gets easier, what gets harder, what we'd need to revisit.
```
