# Instructions for AI coding agents

This repository is ACE PL, a league and fantasy football web app for a community football group.

Before making changes, read:

1. `DECISIONS.md`: agreed product rules. Don't invent rules; ask if something isn't covered.
   `docs/PRD.md` is the original product definition; where they differ, `DECISIONS.md` wins.
2. `docs/ENGINEERING_STANDARDS.md`: size limits, naming, structure, comments, copy, testing.
3. `docs/ARCHITECTURE.md`: layers, folder layout and data model.
4. `docs/TECH_STACK.md`: chosen libraries. Don't add alternatives without an ADR in `docs/adr/`.

The same rules are enforced for Cursor through `.cursor/rules/`, and by ESLint, TypeScript and CI.
